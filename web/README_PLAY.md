# Wyrmbound Vale Browser Play Target

Open `web/play/index.html` directly in a modern browser to test the current public browser demo.

Upload the contents of `web/play/` to hosting for the clickable public prototype. The intended public path is:

```text
openrunt.com/WyrmboundVale/web/play/index.html
```

The Godot project in `game/godot/` remains the future source project. When the Godot Web export surpasses this browser bridge, export Godot to Web and replace or upgrade `web/play/` with the exported browser build.
